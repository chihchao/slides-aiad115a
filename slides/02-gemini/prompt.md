# AI及數位化在小型企業流程的應用
## 認識 Gemini 提示詞

### 語言模型大比拼，誰說得最正確？

#### 任務一：語言模型知道冷笑話嗎？

```
冰塊最想做什麼事？
```
```
老王姓什麼？
```
```
很熱的島是什麼島？
```

#### 任務二：語言模型能規劃旅遊嗎？

```
我和朋友兩個人預計去高雄自由行 2 天 1 夜。
我是極端的 P 型人（隨性、看心情），我朋友是極端的 J 型人（凡事都要列表格、精準掌控時間）。
請幫我們規劃一份『能同時滿足 P 型人驚喜感，又不會讓 J 型人焦慮崩潰』的高雄行程策略指南。
```

#### 任務三：語言模型能掌握當下社群語感與文化嗎？

```
請幫我寫一篇適合發在 Threads（脆）上的短文。
主題是：『為什麼長大後發現，最奢侈的不是買名牌包，而是準時下班和擁有優質的睡眠？』字數在 150 字內，語氣要帶點厭世、幽默，並善用換行與 Emoji，一定要有脆的神隨。
```

#### 任務四：語言模型具有共情能力嗎？

```
請扮演我的『超暖心伴侶』。
我今天工作被主管無緣無故當眾指責，現在心情糟透了，既委屈又憤怒。請對我說一段安慰的話，不需要理性分析對錯或給工作建議，我只需要毫無保留的情緒支持和溫暖的安慰。
```

#### 任務五：語言模型能高情商溝通與換位思考嗎？

```
我的曖昧對象已經兩天沒回我訊息了，但他/她明明一直有發 IG 限時動態。
請給我 3 種不同風格的應對訊息：
1. 幽默化解尷尬型
2. 欲擒故縱高冷型
3. 直球對決關心型
記住，絕對不能顯得太逼人或像恐怖情人。
```


### 以文生圖

```
一張中秋節賀卡，送給全家人。水墨插畫風格，色調以深藍、金色與橙色為主。畫面中央是一輪圓滿的金色明月，月下有一家人圍坐賞月，桌上擺著月餅與燈籠，背景是深藍夜空與銀色雲霧。橫式構圖，家人群像置中，上方留白可書寫「中秋快樂」祝福語。
生成繁體中文文字時，特別注意不要有多餘的筆劃，不要有鋸齒狀，不要有邊緣模糊的情況。
```

### 以圖生圖：修復老照片、變彩色、變風格

#### 修復老照片

```
請修復這張老照片：移除刮痕、污漬和褪色痕跡，補強模糊區域的細節，讓畫質接近現代數位照片，但保留照片原本的構圖與人物面貌，不要改變內容。
```

#### 黑白照片變彩色

```
將這張黑白老照片自動上色，根據照片拍攝年代（約1960年代台灣）推測合理的色彩配置，皮膚、服裝、背景環境都要自然著色，呈現出真實感而非卡通風格。
```

#### 變風格

油畫風：

```
將這張照片轉換成印象派油畫風格，筆觸明顯、色彩鮮豔飽和，光影對比強烈，保留原本人物與場景的構圖。
```

水彩風：

```
將這張照片改成水彩畫風格，色彩透明輕盈、邊緣柔和，有留白感，像手繪插畫。
```

動漫風：

```
將這張人物照片轉換成日式動漫插畫風格，保留人物特徵，眼睛放大、線條簡化，背景可以做成動漫場景感。
```

### 以圖生圖：換服裝、換背景、換風格

#### 換服裝

```
請將照片中人物的服裝換成西裝，保留人物的臉部特徵、髮型與姿勢，只替換衣物部分，讓整體看起來自然真實。
```

#### 換背景

```
請將照片背景替換成日本京都秋天的街道，保留前景人物不變，背景光線與色調要與人物融合自然，不要有合成感。
```

#### 換風格

古典油畫：

```
將這張人物照片轉換成文藝復興時期油畫風格，保留人物構圖，背景改為暗色調畫布質感。
```

賽博龐克：

```
將照片改成賽博龐克風格，霓虹燈光打在人物身上，背景換成未來都市夜景，色調偏藍紫色。
```

漫畫分鏡：

```
將照片轉換成美式漫畫風格，線條粗獷、色塊平塗，加上網點效果。
```
